# Vigías de precios de PdC

Cuatro vigías, uno por país (MEX, COL, CRI y DOM), mantienen al día los precios que
programascontabilidad.com publica de Alegra y de sus competidores. Comparten un solo código.

- Cómo funciona y cómo se construye: `docs/GUIA.md`
- En qué va: `docs/ESTADO.md`
- Qué sigue: `docs/PLAN.md`
- Reglas (borrador): `REGLAS-VIGIA.md`
- Lo propio de cada país: `paises/<vigía>/PAIS.md`
- Señales para reconocer el país: `senales-pais.json`
- Cifras sin país reconocido: `sin-pais.json`
- Skill para Hermes: `hermes-skill/vigia-precios/SKILL.md` (se copia a la carpeta de skills de Hermes)
